# UBD 麦块中文大冒险 v2.0 (UBD Minecraft Chinese Adventure)

专为文莱大学（Universiti Brunei Darussalam）初级华语课程（**LEM-1401 / LM-1403**）打造的 3D 第一人称体素开放校园中文学习 RPG。

## v2.0 大升级亮点
1. **真实 UBD 校园测绘与立体地形**：还原 Dewan Canselor、Language Centre（含东侧山脊高地与 **Tangga Great Wall 长城石阶**真实攀爬高度物理）、Sports Complex、The Core、Medan Selera，以及 5 座预留拓展学院（Library、FASS、FOS、IHS、UBD Mosque）。
2. **3D 立体导师 NPC 与昼夜光影**：10 位像素风导师实体驻守各大楼门前并自动转头注视玩家，支持 `[L]` 键切换**正午 / 金色黄昏 / 星空夜晚**光影。
3. **5 大关卡专属实体互动玩法**：
   - **Act 1 语言中心**：毛笔汉字笔画临摹板（米字格实时笔顺练习）
   - **Act 2 体育中心**：体育场中文口令移动靶射击
   - **Act 3 The Core 市集**：文莱币（BND $）纸币与硬币找零付款台
   - **Act 4 餐厅工坊**：麦块美食量词合成工作台（一碗干捞面 / 一杯热拉茶 / 一盘椰浆饭）
   - **Act 5 总理大礼堂**：UBD 电子结业证书生成与一键下载 PNG
4. **6 大中文学习辅助道具 (`[1]`–`[6]`)**：寻路罗盘、四声色彩透视镜、随身生词本、锦囊排错笔、0.55x 慢速复读机、椰浆饭疾跑双语卡。
5. **外部 JSON 热更新**：编辑 `data/quests.json` 即可在线热更新站点配置。
